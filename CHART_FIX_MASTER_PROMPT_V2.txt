────────────────────────────────────────────────────────────────────────────────

  constructed.

  THE PRINCIPLE: NEUTRAL is UNCERTAINTY; OPPOSITE bias is CONTRADICTION.
  Today the code treats them identically. After this agent:

      (unchanged — a contradicted setup must die);

      period; invalidated only if bias is still NEUTRAL after N consecutive
      15m evaluations; instantly restored if bias returns to the ORIGINAL
      direction within the window.

  requires the CURRENT bias to be non-NEUTRAL and aligned. Grace preserves
  in-flight PROGRESS; it never, under any circumstances, permits an ENTRY
  while bias reads NEUTRAL. This agent does not weaken any entry condition
  — it stops progress from being erased by noise.

APPENDIX B — ENGINEERING CONVENTIONS FOR THIS REPO
────────────────────────────────────────────────────────────────────────────────

  B1.  Java 21, Gradle wrapper (./gradlew or .\gradlew.bat), Node 18+ for
       the dashboard. Root multi-project build works (V1 ledger).
  B2.  One agent = one PR against Main (capital M), squash-merged, branch
       deleted. Fixups are separate small PRs. No direct pushes to Main.
  B3.  Match each file's existing logging convention (SLF4J in the
       connector; System.out in parts of the strategy layer). New code in a
       file follows THAT file's convention.
  B4.  New public types get javadoc explaining WHY they exist. Session-
       scoped/non-durable metrics say so in their javadoc (Agent 06).
  B5.  Concurrency: market-data thread vs API thread. Confined +
       synchronized (ChartEngine pattern), ConcurrentHashMap, or immutable
       snapshots. Never a bare HashMap across threads. Bounded collections
       for anything that grows per event.
  B6.  Determinism is a feature: same candle sequence -> identical outputs.
       Seeded randomness only, and only inside the SIM boundary (Agent 02).
  B7.  Session/killzone logic is America/New_York; candle timestamps are
       Instant (UTC). Never mix silently.
  B8.  Risk code (M1–M9 semantics, PropFirmRiskEngine, RiskLimits, DLL/MLL,
       flatten times) is READ-ONLY. Telemetry may observe; nothing weakens.
       Agent 04 touches invalidation timing ONLY, guarded by a tested
       invariant, default OFF.
  B9.  Secrets only via environment variables. Never in source, logs, or
       commits.
  B10. Every async/UI surface: loading, empty, error, and (new) COLD states
       handled. An endpoint hit before warmth returns an honest empty shape,
       never a 500.
  B11. Additive over invasive: V1's byte-identical, smoke-tested classes are
       extended, not rewritten. Pre-existing tests passing UNCHANGED is the
       proof that defaults were preserved (Agent 05).
