HOW IT WORKS — THE 30-SECOND VERSION (plain English, for the owner)
--------------------------------------------------------------------------------
  1. The strategy is rewritten in Pine Script and runs on a TradingView chart
     (MNQ). TradingView's servers watch the chart around the clock. Your
     computer can be OFF.
  2. When every rule lines up (raid → MSS → displacement → FVG/OTE, inside a
     killzone, bias agrees), the script fires an ALERT. An alert is just a
     short text message: "BUY 2 MNQ, stop X, target Y".
  3. TradingView sends that message to a RELAY (CrossTrade by default). The
     relay is logged into your Lucid Tradovate account(s).
  4. The relay places the order on Tradovate WITH the stop and target attached,
     on every Lucid account you linked. Same direction on all of them.
  5. You see the trade in TradingView's Tradovate panel like any other trade.
  6. Your Java engine stops trading. It becomes the TEST LAB: it replays real
     data and proves the TradingView version takes the SAME trades.

  The account plan doesn't matter to the strategy. A setup is a setup. The
  plan only sets the hard caps (max contracts, flat-by time), and those
  live in ONE settings block.
